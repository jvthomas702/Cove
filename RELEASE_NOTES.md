# Cove 1.2.0

- A consistent black interface across the island, AI workspace, Settings and image editor, including under Light macOS appearance.
- Labeled navigation, larger controls, calmer transitions and more forgiving hover timing. Click the island or a tab to keep it open.
- Music, live sports scores and latest play, activity and AI connections together on Home. Open the full Gamecast from Sports or Play-by-play.
- The AI workspace has Cove’s original Pip companion, reported activity steps, live detail and direct All / Live / Done filters. Filtered details and empty states stay in sync.
- Type a task in the AI tab, choose Codex or Claude Code and a project folder, then Start. The installed interactive agent opens in Terminal with its existing login and permissions. Connected lifecycle events appear in Cove.
- Connect AI is visible on every tab. Devices groups the macOS sound, display, Wi-Fi and AirDrop settings shortcuts.
- Signed in-app updates replace manual app downloads. Use Cove → Check for Updates or Settings → About. New installations enable automatic download/install by default; existing preferences remain available there.

## Updating an existing Cove

Choose **Check for Updates** in Cove and install the offered update. Cove downloads the signed archive, replaces the installed app and relaunches. There is no need to unzip or drag a new app into Applications.
