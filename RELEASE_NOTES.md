# Cove 1.8.0

**Talk to Claude**
- Hold fn (🌐), speak, and release to send. Cove shows your transcript and streams Claude Code’s answer into the island.
- Ask a follow-up within five minutes to continue the conversation. Esc cancels listening.
- Choose Claude’s working folder in Settings → AI agents → Talk to Claude.
- Optional read-aloud replies and automatic file edits, both off by default. Requests that need approval can continue in Terminal.
- Microphone and speech recognition permissions are requested on first use. Recognition runs on-device when supported. Accessibility lets the fn shortcut work while other apps are active.
- Quick fn taps and fn used as a modifier do not start listening.

This update keeps your existing settings and updates Cove in place.
